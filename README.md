# Проект: Разработка UI-компонентов и страниц на React

## Описание
Этот проект включает создание библиотеки UI-компонентов, страниц и интеграцию с API. 

---

## Функциональность

### Разработка компонентов

#### **1. Кнопки (Button)**
- **Типы кнопок**:
  - `primary` (основная).
  - `secondary` (второстепенная).
  - `outline` (с обводкой).
- **Формы кнопок**:
  - `rounded` (скругленные края).
  - `square` (прямоугольная форма).
- **Дополнительные возможности**:
  - Поддержка состояния `disabled`.
  - Реализация специализированных кнопок-ссылок:
    - **GoToLink** — ссылка с жирным стилем.
    - **ShowMoreLink** — ссылка с оранжевым цветом.
    - **BattonLink** — кнопка-ссылка для добавления.

---

#### **2. Поля ввода**
- **InputEmail**:
  - Поле для ввода электронной почты.
- **InputPassword**:
  - Поле для ввода пароля с поддержкой скрытия введенного текста.

---

#### **3. Модальное окно (Modal)**
- **Особенности**:
  - Реализация универсального модального окна.
  - Возможность управления видимостью через внешнее состояние.
- **Применение**:
  - Для подтверждения действий, отображения информации или форм.

---

#### **4. Якоря (Anchor)**
- **Особенности**:
  - Универсальный компонент для создания ссылок-якорей.
  - Поддержка навигации к указанным разделам страницы.

---

#### **5. Всплывающие подсказки (Tooltip)**
- **Особенности**:
  - Появление подсказки при наведении на элемент.
  - Настройка позиции подсказки: сверху, снизу, слева или справа.
- **Применение**:
  - Для отображения дополнительной информации о кнопках или других элементах интерфейса.

---

#### **6. Форма регистрации (RegistrationForm)**
- **Поля ввода**:
  - Электронная почта
  - Пароль
  - Подтверждение пароля
  - phone
  - city
  - birthDate
  - profileLink
- **Проверка полей**:
  - Проверка обязательности всех полей.
- **Интеграция с API**:
  - Отправка данных пользователя для регистрации.
  - Отображение ошибок или успешного сообщения.

---

#### **7. Форма авторизации (LoginForm)**
- **Поля ввода**:
  - Электронная почта.
  - Пароль.
- **Кнопка отправки**:
  - Поддержка состояния загрузки (`loading`).
- **Обработка ошибок**:
  - Сообщения об ошибках при пустых полях или неверных данных.
- **Интеграция с API**:
  - Использует моковый API `loginUser` для обработки запросов.

---

### API

#### **1. Моковое API**
- **Функция loginUser**:
  - Эмулирует процесс авторизации пользователя.
  - Возвращает успешный ответ или ошибку.
- **Функция registerUser**:
  - Эмулирует регистрацию нового пользователя.
  - Проверяет корректность данных и возвращает результат.

### Страницы

#### **1. Домашняя страница**

Компонент `HomePage` представляет собой основную страницу приложения, которая включает:

- **Layout**: Обеспечивает базовую структуру страницы, включая хедер, футер и область для основного контента.
- **Section**: Выделяет блоки на странице для логического разделения.
- **Modal**: Используется для отображения форм в модальных окнах.
- **LoginForm**: Форма для входа в систему.
- **RegistrationForm**: Форма для регистрации нового пользователя.
- **ButtonLink**: Компонент кнопки со стилями и действиями, подключенный через общую библиотеку.

## Основной функционал
- Кнопки для входа и регистрации (`Войти`, `Присоединиться`), которые открывают соответствующие модальные окна.
- Использование компонентов с переиспользуемыми стилями (`ButtonLink`, `Layout`).
- Управление состоянием модальных окон с помощью `useState`.

#### **2. Страница авторизации**
- Содержит компонент `LoginForm`.
- Обрабатывает ввод пользователя и отправляет данные на сервер.

#### **3. Страница регистрации**
- Содержит компонент `RegistrationForm`.
- Включает валидацию и обработку ошибок.
- Отправляет данные на сервер для регистрации.

## Routes
Файл маршрутов отвечает за определение путей приложения и соответствующих им компонентов, которые рендерятся при переходе по этим путям. В данном случае используется библиотека react-router-dom.

### Описание файла маршрутов

- path: URL-путь, который обрабатывается маршрутизатором.
- element: Компонент, который будет отрендерен при переходе по указанному пути.

### Маршруты, описанные в файле

**Главная страница (/)**

- Компонент: `HomePage`
Описание: Главная страница приложения, которая отображается при переходе по корневому пути (/).

**Страница регистрации (/register)**

- Компонент: `RegistrationPage`
Описание: Страница регистрации пользователя. Переход по этому пути открывает форму регистрации.
